# PianoPlayer
We have made an Midi to Lua Player script only for github script and we dont have a function for that other players can use their custom Lua Script.
We will make it later. 
## How to make a Midi2Lua
use this website [Midi2lua](https://shadowdev1231.github.io/midi2piano) to make the files

## HOW TO LOAD THE PIANO PLAYER
Use this Lua/Luau loadstring for to use the piano player.
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ShadowDev1231/PianoPlayer/refs/heads/main/main.lua"))()
```
